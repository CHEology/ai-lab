# AI Lab 设计规范

生效：2026-09-05。此次目录层级依据作者提供的文件夹列表参考图；配色、图标、字体和阅读页采用 AI Lab 自己的统一设计。

文字页面的段落、标题、注释、引用来源、键盘往返和验收细则，以 [文字排版与引用规范](WRITING-DESIGN.md) 为准（2026-09-08 制定，agent / AI 编辑前必读）。本文件继续负责全站标识、目录、配色和地址。

## 目录

- 保留原 ai-lab 字标的字体、倾斜蓝色色块与星号；首页大字标，内容页使用同一标识的小尺寸版本。
- 首页与文字目录使用原生 `details/summary` 文件夹，默认展开已有内容。细线文件夹表示分组，文件图标表示文章，缩进和 1px 连线表达父子关系。分类只为真实条目建立。
- 首页结构为“文字 → Blue Note 回应 → 四篇标题”。“文字”右侧保留小型“目录 ↗”链接，可直接进入 `/writing/`。展开操作与页面链接互不替代；键盘与无 JavaScript 均可用。
- 文件夹行至少 48px，文件链接触控高度至少 44px。正文条目 16px，一级分组 18px，待写状态 12px。手机减少缩进，不压小文章文字。
- 待写作品明确标“待写”；不编造摘要、创作日期、模型或活动统计。不使用高饱和多色图标、背景几何装饰、卡片或加载骨架。

## 配色与阅读

共享样式在 `site/assets/style.css`。浅色纸面 `#f3f4f5`、正文 `#171c22`、链接 `#245ac1`、辅助文字 `#656d77`、细线 `#c7cbd0`；深色分别为 `#25282c`、`#e3e6eb`、`#a6c5ff`、`#b0b8c4`、`#515966`。字标蓝块使用原有 `#78aaff`，块内文字仍为深色。所有页面自动跟随系统外观，不新增外观切换控件。

阅读页维持中性纸面，使用 Charter / Georgia 和中文宋体的衬线字体栈，正文 17px、行距 1.78、最大行宽 39.667rem。标题约 32px、手机约 26px。目录与工具性导航使用系统无衬线字体。两者共用颜色与间距尺度。

内容页上方只放小字标和所在目录；原文链接位于正文末尾，用 4rem 的短细线、14px 文字和留白隔开，不放版本切换条。AI Lab 独立实现样式，不导入 Blue Note 的主题、CSS 或运行脚本。

正文引用使用小型上标注号，事实与分析分清落注位置。文末按“注释 → 延伸阅读（若有）→ 原文入口”排列；原文首次篇名也可直接链接。注释 15px、行高 1.75，保持正文颜色；注号与返回箭头使用无脚本锚点。禁止恢复段尾括号域名格式。维护规范只放仓库入口，不加入读者目录。

文章目录为作者许可后的单篇选项，置于日期与正文之间，默认收起，仅列主要 H2；使用小折角、14px 无衬线文字与底部细线。数学公式在构建时生成 MathML，继承阅读字号和配色，无浏览器脚本或 CDN。执行细则见文字规范。

## 地址与状态

回应页末级 URL 必须等于原文标题；中文保留，空格和标点按 URL 标准编码。文件系统保存 Unicode NFC 标题，不使用拼音别名。发布后的标题路径不能随意改变。

有独立标题的回应通过 `responseTitle` 指定阅读页的 H1 和浏览器标题；目录名称与地址继续使用原文标题 `title`。正文不重复 H1，不因新增回应标题而改动原文入口。

pending 页仅包含“回应尚未发布。”及原文返回入口，使用 `noindex, follow`。published 页显示选定正文和真实发布日期；有实际署名时一并显示，未提供时只显示日期，不加占位文字或多余分隔符。draft 不进入生成产物。

## 验收

运行 `npm run check`；检查桌面 1280px、手机 390px，以及窄屏 320px。检查明暗主题、文件夹键盘展开／收起、无脚本操作、中文／空格地址直达、原文往返、单一 H1、资源无 404、无横向溢出。文章正文尚未交付时不得以示例内容填充线上页面。
